# MyWindowsMediaPlayer

A custom media player inspired by Windows Media Player, written in C# with WPF.

## Stack
- C#, WPF / XAML
- .NET Framework 4.0 (Client profile), x86
- MVVM architecture

## Structure
- `Model/`: classes and services
- `View/`: `MediaPlayerView.xaml`
- `ViewModel/`: `MediaPlayerViewModel.cs` and interfaces
- `converters/`, `Behaviors/`, `Helpers/`

## Run
Open `MyWindowsMediaPlayer.csproj` in Visual Studio (2015 or newer) and run. Windows only.

## Status
Archived, no further development planned.
